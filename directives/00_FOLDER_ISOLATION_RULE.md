# 🔒 폴더 완전 독립 격리 원칙 (FOLDER ISOLATION RULE)
**우선순위: CRITICAL — 모든 작업 전 필독**

## 📌 핵심 원칙 (절대 불변)
> **모든 앱 폴더는 서로 완전히 독립된 별개의 프로젝트다.**
> 어떤 경우에도 폴더 간 파일 공유, 참조, 심볼릭 링크, 상대경로 연동을 금지한다.

## 🏗️ 폴더 생성 방식 (대표님 전용 프로세스)
1. 새 앱이 필요할 때 **대표님이 직접** 템플릿 폴더를 복사하여 새 이름으로 붙여넣는다.
2. 복사된 새 폴더 안에는 `AGENTS.md`, `directives/`, `execution/`이 기본 포함되어 있다.
3. AI는 새 폴더 생성을 위해 기존 폴더를 스스로 복사하거나 상위 폴더를 건드리지 않는다.

## 🎯 AI 작동 범위 원칙 (SCOPE RULE)
> **AI는 현재 작업 폴더의 파일만 수정하며, 타 폴더 수정은 대표님의 명시적 지시가 있을 때만 허용된다.**

- **현재 폴더 작업:** ✅ 해당 폴더 안 파일만 수정
- **명시적 지시 ("X 폴더에도 동일하게 적용"):** ✅ 명시된 폴더에만 적용
- **AI의 자의적 타 폴더 일괄 업데이트:** ❌ 절대 금지
- **유사 폴더 자동 스캔 및 변경:** ❌ 절대 금지

## ❌ 에이전트 필수 점검 (금지 사항)
- 경로에 `../` 등을 사용하여 다른 폴더의 파일(`파일.js` 등)을 참조하지 마라.
- 공통 코드가 필요하면 상위에 두지 말고, 해당 앱 폴더 안에 직접 복사하여 독립적으로 관리하라.
- Firebase 배포는 반드시 해당 앱 폴더(`Cwd`) 안에서만 실행하여 덮어쓰기 에러를 방지하라.
