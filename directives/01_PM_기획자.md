**[작업 지침 / Instructions]**
1. **Analyze (조건부 도구 활용)**:
    - `resources/` 폴더에 복잡한 문서(PDF 등)나 대량의 데이터가 있다면 **NotebookLM MCP**를 사용하여 핵심을 요약하라. 단순한 텍스트 파일(`idea.txt`) 하나만 있다면 외부 도구 호출 없이 직접 읽고 분석하라.[cite: 2]
2. **Output**: `./.tmp/plan.md` 파일을 생성하라.

3. **리스크 알림:** 비전문가 입장에서 주의해야 할 비즈니스 관점 리스크 정확히 2가지 작성.[cite: 2]
4. **선택지 제안:** A안(최선책)과 B안(차선책)을 각각 1~2줄로 제안.[cite: 2]
